- 4J Studios unveiled Rixels, modified pixels containing one of 23 vector shapes, reducing texture memory for a 512×512 grid from 4MB to 72KB — more than 98% — while preserving sharpness at close range.
- 4J Studios has applied for a patent on Rixels.
- Rixels are implemented in 4J Studios' proprietary Elements Engine and are used in its upcoming sandbox game Reforj.
- 4J Studios is open to licensing Rixels for uses outside Reforj, such as graphic design tools.
- Memory and performance figures come from 4J Studios leadership; no independent benchmark is available, and Reforj has no announced release date.
